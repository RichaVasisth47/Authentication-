# Flask Authentication Project 🔐

A secure user authentication web application built using Python, Flask, Flask-Login, and SQLAlchemy. This project handles user registration, secure password hashing, login sessions, and protected profile routing.

## Features
* Secure user registration and login system with hashed passwords using Werkzeug security.
* Session management powered by Flask-Login (`current_user`, login/logout routes).
* Database integration using SQLAlchemy and SQLite for storing user credentials safely.
* Clean and responsive frontend template integration.

## How to Run Locally

Follow these steps to set up and run the project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/RichaVasisth47/Authentication-.git](https://github.com/RichaVasisth47/Authentication-.git)

Navigate into the project folder:
Bash
cd PythonProject-Authentication

Install the required dependencies:
Bash
pip install -r requirements_3.13.txt

Run the main application file:
Bash
python main.py

Open in browser:
Visit http://127.0.0.1:5000 to view and interact with the application.
